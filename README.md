# Applied Data Science Capstone

Final capstone project for the **IBM Data Science Professional Certificate**. 


## Objectives

- Collect launch data via the SpaceX REST API and web scraping
- Clean and wrangle the data into a usable format with Pandas
- Perform exploratory data analysis (EDA) using SQL and Python
- Visualize trends and relationships in the data
- Build an interactive dashboard using Plotly Dash
- Visualize launch site locations with Folium
- Train and evaluate machine learning models to predict landing outcomes
- Communicate findings and results to stakeholders

## Tools & Technologies

`Python` `Pandas` `NumPy` `SQL` `Matplotlib` `Seaborn` `Plotly Dash` `Folium` `Scikit-learn` `Jupyter Notebook`

## Project Structure

- **Data Collection** – Gathering launch data via API requests and web scraping
- **Data Wrangling** – Cleaning and preparing data for analysis
- **EDA (SQL)** – Querying and exploring the dataset with SQL
- **EDA (Visualization)** – Uncovering patterns with charts and plots
- **Interactive Map (Folium)** – Visualizing launch sites and outcomes geographically
- **Dashboard (Plotly Dash)** – Interactive dashboard for exploring launch data
- **Predictive Modeling** – Training classification models to predict landing success


## Key Findings

- Launch success improved significantly over time, particularly from 2013 onward, with the highest success rates around 2019–2020.
- KSC LC-39A emerged as the most reliable launch site, with a 76.9% success rate in the analysis.
- Payload mass and launch success showed a positive relationship in the analysis; many higher-payload missions were successful.
- Among the tested models, the Decision Tree performed best, achieving over 87% accuracy and recording zero false negatives in the shown confusion matrix.
